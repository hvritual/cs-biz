# r004 实现设计与保护行为

只修改本任务文档、`frontend/apps/console/src/design/f-series/` 下的隔离预览和对应 focused 测试。沿用 MODE=design、127.0.0.1:5790 专用 origin 与现有安装守卫。生产构建和正常业务路由不得包含可访问预览。保持旧 32 页、原断言和 Mobile skip。

复用 full/state 的当前账号/企业、当前 grants、事务验证、版本快照和原操作 ID；新增就地提交入口不能绕过 guard、validate 或 transaction。不改变后端授权或协议。普通旧逐页路径仍可复核；新路径的提交在原页面展示 LocalOutcome 并读取同一原操作，不制造第二份结果。

统一选择组件输入：filter/paste/excel 三种方法；输出固定的已核对编号数组及错误分类，永不提交。严格模板字段 `编号`（客户/资源）或 `邮箱`（邀请）；支持可选 `名称`，未知/重复表头和公式明确拒绝。单文件最多2MiB，展开总量最多8MiB、1000行；只支持无加密的 .xlsx，保留文本编号与前导零，数字编号格式不明时要求改为文本；不得默默猜测精度。XML外部实体不允许，路径穿越/重复ZIP部件/压缩炸弹拒绝。单元格内容只作为数据。

匹配在当前企业与当前动作范围内执行；不可见/不存在统一反馈；可读不可写只解释当前可见对象的动作限制。去重按最终对象ID，名称歧义需要唯一选择或排除。改变筛选不扩大集合；企业/账号/角色切换清空选取和旧对话框。提交时重新验证当前权限、模块、版本和负责关系。预览写入只落隔离本地存储。

结果组件按 Task.items 实际状态计算总数/已完成/失败/处理中/待核实，每项给出理由/后续。查询使用原 Task ID，终态不改写；失败恢复保留成功项与未知项，仅对当前仍可授权和版本适用的明确失败项创建新的已确认操作。导出下载沿用当前权限/过期检查。

操作示意采用项目内 SVG/DOM 可访问图形，明确选取→影响→确认→结果的位置，配短说明/alt；使用现有 token、品牌色和 Element Plus，不添加第二主题。

任务连续性：父 #10 与 #13–17/#19 保持原分母；本轮只准入 Design/Preview。原业务实现、合并和生产均无本轮授权。接受阶段等待同版 Human 审阅，不签 Build handoff。
