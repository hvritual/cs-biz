# r003 全流程旅程

每一步对应screen-inventory中的稳定UI编号；状态以page ID + scenario ID定位。以下是用户动作链，场景下拉框只是外层审阅工具，不能替代动作链验证。

| 旅程 | 角色/入口 → 操作 → 结果 | 异常与恢复 |
| --- | --- | --- |
| J01 可信进入 | 登录→组织账号验证→0/1/N企业分流→选择→企业上下文 | 验证失败/过期/重放/身份不匹配重新发起；切换失败清旧权限；离线保留安全返回入口 |
| J02 会话与标签页 | 账号设备→查看→撤销单设备或退出全部；A/B标签各选企业→刷新 | 当前会话撤销清可见数据、全部标签页退出；重登后按原企业查询原操作，不自动重放 |
| J03 企业开通 | 平台企业列表→创建→校验负责人建立方式→确认→原记录；详情→模块配置→影响确认→生效读回 | 重复标识/非法负责人/无权/未发布模块拒绝；创建者不自动成为Owner；首回执丢失先查原记录；不含付费订阅 |
| J04 成员管理 | Owner成员列表→筛选/详情→改角色/停用/移除/恢复→确认→记录和审计 | invited非active；最后Owner拒绝；版本并发/撤权/安全校验先重核；敏感写不借旧角色继续 |
| J05 邀请全程 | 邀请记录→文本输入→校验/去重/已有成员→角色与范围→确认→逐项结果/投递→受邀者验证身份→接受 | 不匹配/撤回/过期/已使用/停用拒绝；部分/未知逐项查询；输入修改不覆盖旧批次；IdP负责密码/MFA恢复 |
| J06 授权 | 角色列表→新建/编辑→菜单与逐动作Scope→差异→确认→生效回读 | 非法/未知grant拒绝，委派不扩权，不拼不同动作范围；保护最后Owner；并发先读新版本 |
| J07 营销 | 营销入口→列表/详情→本人活动→核对草稿到启用→确认→结果→操作详情 | 有Function无Menu可执行；有Menu无Function/模块关/越Scope/停用/跨租户拒绝；unknown先查原ID；不含外部触达/扣费 |
| J08 客户 | 列表筛选/分页/统计→详情→有权修改→差异确认→结果 | READ tenant与UPDATE self分离；不可访问统一隐藏；owner/版本/权限变化先重核；空态/加载/离线不同反馈 |
| J09 批量/导出 | 粘贴客户ID/名称→解析→歧义消解/排除→当前可授权集合→影响→确认→逐项结果/导出记录 | 不能跨tenant搜索；已完成保留、未知先查、失败单独处理；导出下载重验当前权限与有效期，不静默扩大筛选集合 |
| J10 操作恢复 | 操作列表→原操作详情→进行中/成功/失败/部分/未知→当前权限下查询 | ID不匹配/异参key冲突拒绝；取消等待不撤销已提交；任务终态不改写；重启/刷新保留原ID |
| J11 异步处理 | 运维查看后台记录→事件链/重试/死信→查业务效果→获准人员接管 | 不可信主体不继承；外部效果未知禁盲重放；RPC/Child失败显示业务边界，不伪造前端配置传输协议 |
| J12 诊断 | 业务失败或页面错误→安全排障号→获准支持搜索→span/log/event来源→原业务结果 | 无采样/源不可用/部分/跨tenant拒绝明确；不暴露PII/秘密；复制失败可手动复制；Trace不证明效果 |
| J13 观测与审计 | Owner查审计；运维查stdout/本地采集/可选SLS及队列与丢弃 | SLS关/故障/过期/限流不改业务授权；诊断无权不回退全局检索；样例非真实采集证明 |
| J14 发布资格 | 运维固定候选/Consumer/schema/环境→材料核对→迁移/备份恢复/隔离安全/容量→计划 | 缺SLO/证据/环境/授权阻断对应阶段；不把单元或设计CI当生产资格 |
| J15 灰度与恢复 | 目标与范围→差异与风险→确认→进度/阶段观察→暂停/继续→终态；恢复计划→兼容/数据风险→确认→读回 | 部分/失败/unknown保留已生效范围，先读回不重发；回滚不能承诺撤销外部效果；未知目标/操作者无实际发布权限 |

公共恢复：保留当前对象、输入、原操作和支持编号；当前身份/企业不符时先重选，不能带旧tenant写入。租户/角色变化关闭旧对话框与选择，已完成记录仍归原账户+tenant；返回列表恢复适用筛选和焦点。

Access补项沿J06/J08/J09现有页面：同一林沐成员同时具有“只读成员+负责客户可写”，核对全客户可读/本人客户可写，撤销写角色后保留读取且写/导出拒绝；周明范围管理员可授予assigned与explicit角色，明确资源指派、非本人客户允许写、撤销指派后explicit仅保留读取，再调整explicit集合后旧对象不可访问。实际浏览器连续验证另记，不将样例行为替换原真实API/DB验收。
