# F2–F6 完整交互设计 · r003

本版供同版业务设计审阅。页面使用现有CoffeeLink Console，数据和操作隔离为审阅样例，不发送邀请、不触达客户、不变更线上环境。业务F2–F6/O1并未因此完成。

## 怎么审阅

从登录入口继续，用组织账号进入企业。顶部审阅工具可切换全部32个页面、声明场景、账号和能力样例；左侧为审阅导航，不代表真实菜单授权。平台页面选择“平台管理员”，诊断选择“获准支持人员”，遥测/发布计划选择“获准运维人员”；组织业务选负责人或业务成员。切换能力只收窄样例权限，不能覆盖已保存的成员降级或模块关闭。

建议先走登录→企业选择→营销活动→启动确认→原结果查询，再看成员与角色、邀请创建/接受、客户修改/文本批量/导出，最后看受控诊断与非生产资格页面。记录可跨刷新保存。重置全部审阅样例会清除本版样例操作。

## 本版设计内容

- 32个页面与233个声明场景，原始验收对应见[页面清单](screen-inventory.md)。
- 登录/恢复、0/1/N企业、标签页上下文、受邀身份验证、首次负责人及失效重发、逐动作角色委派和最后Owner保护。
- 同成员多角色按动作并集、可核对的assigned资源指派与explicit指定集合，逐项撤销后实时收窄。
- 菜单与营销Function分离、客户读取/修改/导出独立Scope、文本匹配/去重/消歧、明确选定集和逐项恢复。
- 提交结局先持久保存，回执丢失后只读原结果，不重新执行；当前权限变化后再核查询与文件下载。
- 受控诊断、审计、事件因果、stdout/可选SLS，以及发布资格与恢复计划的可审阅表达。运维页属于证据/计划表达，不追加真实生产控制台承诺。
