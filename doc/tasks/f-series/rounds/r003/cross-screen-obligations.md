# 跨页面与异常交互契约

这些是独立范围审查补出的必测动作，不以场景标题出现代替通过。审阅角色只是fixture能力组合；真实授权依当前动作及Scope，不固化“仅Owner能管理”的未批准替代策略。

| ID / 原义务 | 入口与动作 | 不变量、异常和恢复 | 预期验证 |
| --- | --- | --- | --- |
| X01 AC07 | 有营销Function无Menu→活动→确认启动→结果→后台深链 | 营销成功与Console深链拒绝同时成立；返回原企业原操作；有Menu无Function拒绝且无效果 | 真浏览器点击/路由/回执/日志 |
| X02 AC09/10 | 同一主体READ=tenant/UPDATE=self→列表/详情/批量/导出 | 能读非本人、不能改非本人；每动作Scope独立；模块关闭/撤权后当前打开详情/导出下载也拒绝 | 前端交互+后续真实SQL/API义务 |
| X03 AC05/08 | 同账号A/B两个实际标签页→各操作unknown→交叉刷新/查询→切换失败→退出/重登 | tenant独立，晚到A结果不能覆盖B；原ID/逐项状态保留；失败不复用旧企业权限；退出跨标签生效 | 同一浏览器context真实双页与重载 |
| X04 AC06/08 | 写前稳定key→取消/双击→相同参数→异参冲突→首回执丢失→原ID查询 | 取消无记录；双击一个操作；异参不覆写；终态不可回退；无当前权限不读原结果 | 本页交互/锁竞争/记录和domain差异 |
| X05 AC06/09 | 批量输入→去重/格式/已有成员/未匹配/不可访问/歧义→消歧/排除→最终集合→确认 | 输入修改使预选失效但不覆盖原批次；按项成功/失败/未知，未知先查、成功不重做；原子活动启动不出现未定义部分成功 | 实际表单、逐项结果及重新进入 |
| X06 AC03/06 | 登录/会话→IdP密码/MFA恢复交接→完成或取消→重新登录 | SaaS不收密码/验证码，不暗合并issuer身份；0企业账号仍可退出/撤销会话；匿名不能管理会话 | 匿名/已认证无企业/成员角色差异 |
| X07 AC06 | 有委派权管理员→角色动作/范围→未知权限或legacy group→确认 | 允许有界委派，不仅Owner；未知/legacy范围拒绝；不同动作范围不可拼接；自己没有的范围不可授予 | 编辑交互、拒绝无effects、合法保存 |
| X08 AC06 | 成员/角色修改→最后Owner或并发Owner移除→转交确认→提交 | 至少一名在任Owner；转交目标必须当前active；角色编辑/停用/移除/自降级均保护；先读最新再确认 | 多入口实走；真实DB竞争仍后续 |
| X09 AC11/12/13 | 同步失败/子操作失败/后台retry或deadletter→操作详情→诊断→业务回读 | Trace/event不证明效果；外部结果未知不得盲重投；非敏感输出、跨tenant拒绝 | 可操作查询；真实transport/UoW/Outbox仍后续 |
| X10 AC14/15 | 观测SLS关闭/故障/限流→资格材料→发布或恢复审阅 | stdout/授权不因采集故障改变；未获生产P6/材料阻断；UI是可选运维证据/模拟审阅，不新增生产控制台交付承诺 | 交互审阅+后续真环境证明 |

旧原件不改。本轮新增工作只兑现完整设计与可审阅界面；以上浏览器通过仍不能填原业务R/AC已完成。
