# W05：面向 Agent 推进任务的文档与 Skill 整理

## 目标、来源与边界

来源：2026-10-16 Human 要求移除无实质意义的 Skill/文档、更新陈旧内容，并按架构职责整理，使后续整体任务推进可用且对 Agent 友好。基线 main `29c525d7f90cf61075f00a20efc1465a29b2c6db`。本会话延续仓库写入、PR、合并与回读授权；不启动业务 Issue 实施或生产部署。

成果：Agent 从 AGENTS / 文档入口能按当前目标找到唯一的阶段能力、设计/实现/验收依据、现行门禁、真实任务状态和缺失条件；不会读到相互冲突的现行指令，也不会把历史确认或候选误当当前实现。

WHY：四个仅转发的 Skill 和重复 UX 副本增加发现噪声；S00/S01 状态、F0/F1 投影与旧 Human-only CI 叙述已落后于 main。
WHAT：收敛入口、所有权与当前状态，保留实质方法/契约/检查；删除重复入口，建立按需导航和确定性文档检查。
BOUNDARY：仅项目文档、Skill 说明/资源、必要结构检查/测试和统一 CI 接线。业务实现、依赖/生成/部署配置、裁判和原产品断言不变。
PROOF：原回归、所有权/链接/删除引用/历史字节保护反例、Agent 冷启动找路、独立内容审查、精确候选与 main Full/回执。

## 整理规则

- 当前约束只保留一个权威位置；入口提供选择和链接，不复制整套规则。
- 每个 Skill 保留独立触发条件、决策/产物/验证职责；只转发的旧名字删除，实质方法归所属工作流。
- 当前产品状态由源码、合并/Issue/CI 回读支持；roadmap 为有日期和基线的投影，继续工作前须刷新。
- 冻结 rounds/handoffs、既有验证原件和历史试用字节不改；旧命令/状态明确为历史，只按所记版本复现。
- 旧协议 CLI 保留，因为已有真实消费者和兼容测试；空文档指针与一次性过期 pilot 不作为常驻入口。
- ADR 更新明确采纳范围/来源，不能扩大为已实施或部署，也不改变批准的业务定义。
