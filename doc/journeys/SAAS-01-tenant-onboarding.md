# SAAS-01：租户开通、成员授权与实际使用

- 状态：设计完成，运行未实现。
- 目标：让一个新租户的成员按已经生效的模块和权限完成一次真实业务操作，并可证明另一租户无法访问其数据。
- 推荐首期机制：平台人工开通模块并写入生效权益，不接入付费流程。
- 角色：平台管理员、租户负责人、只读成员、禁用成员。
- 数据：租户 A 与 B，各有独立测试用户和至少一个持久化资源。

## 操作与结果

| Screen ID | 角色与操作 | 用户必须看到的结果 | 必须验证的异常 |
| --- | --- | --- | --- |
| S01-01 | 平台管理员打开租户列表 | 真实租户状态、检索与创建入口 | 无权限管理员不能创建 |
| S01-02 | 创建租户并指定负责人建立方式 | 可核对的租户与负责人信息 | 必填、重复标识、非法负责人 |
| S01-03 | 确认创建 | 唯一租户记录与操作结果 | 首次提交前保存幂等键，双击、超时、首回执丢失均可恢复，不重复创建 |
| S01-04 | 负责人首次进入，无商业模块权益 | 明确尚未开通，可处理基础企业设置 | 空菜单不显示成系统故障；不伪造已订阅 |
| S01-05 | 平台选择可开通模块、期限/额度 | 具体待生效配置与影响 | 未发布或禁用模块不能被任意开通 |
| S01-06 | 确认开通并回读权益 | 生效权益、操作 ID 与审计 | 回执丢失不重复开通；不可静默改价或扣费 |
| S01-07 | 负责人管理成员 | 成员的加入/邀请/停用状态 | 不能加入其他租户数据；重复邀请可识别 |
| S01-08 | 配置角色与数据范围 | 动作权限、范围、模块依赖可核对 | 不能授予超出管理范围的角色；未知权限拒绝 |
| S01-09 | 成员登录并选择租户 | 当前租户标识、有效菜单、可用动作 | 禁用/未加入成员受控拒绝 |
| S01-10 | 成员进入列表并打开真实资源 | 只出现授权范围内数据 | 修改 URL、直调 API、伪造 tenantId 均不能越权 |
| S01-11 | 执行被允许的写操作，或验证只读状态 | 明确提交中、成功、失败或结果未知 | 只读角色不能通过直调 API 写入 |
| S01-12 | 切换到另一个租户 | 新租户菜单、主题与数据一致 | A 的迟到请求不能覆盖 B；另一标签页写入目标不改变 |
| S01-13 | 管理员撤权、停用成员或关闭模块 | 新请求被拒，前端清理过期访问状态 | 已打开页签、缓存、导出、下载、批量接口均受约束 |
| S01-14 | 刷新、重新登录和重新授权后恢复 | 恢复当前真实权限与操作结果 | 不依赖旧 localStorage 权限，不重复执行未知结果命令 |

## 用户体验约束

所有步骤需分别覆盖 `zh-CN` / `en-US` 和 light / dark。页面持续显示当前租户，避免在不同租户下误操作。表格、表单校验、弹窗、提示和日期格式要一致；无权限与未开通使用不同且可理解的原因。

平台开通与租户负责人申请开通是不同角色动作。首期未实现商业订阅，不展示虚构套餐价格、支付状态或自动续费承诺。

## 最小验收矩阵

| 组 | 场景 | 预期 |
| --- | --- | --- |
| A | 模块已开通，成员有动作权限且资源在范围内 | UI 与真实 API 允许 |
| B | 模块未开通，成员角色含该权限 | 业务入口受控；API 拒绝 |
| C | 模块已开通，成员无动作权限 | 不能执行；直调 API 拒绝 |
| D | 权限有但资源属于另一租户或范围外 | 列表不出现；详情/写入/导出拒绝 |
| E | 成员被停用或授权失效 | 服务端按当前规则拒绝，前端更新 |
| F | 切租户并有延迟请求、旧页签和另一标签页 | 无数据串用，无写入目标混淆 |
| G | 创建/开通首回执丢失、同键同参数并发重试、同键不同参数 | 预存键可查询恢复；前者一个业务结果，后者 409，不重复执行 |
| H | 主题/语言切换后刷新、退出再登录 | 按用户/租户规则恢复，业务语义不改变 |
| I | 同一成员同时有“全部客户只读”和“负责客户可写”两个角色 | 可以读取全部客户，只能修改负责客户；直调 API、批量和导出分别按对应动作的范围判断 |

## 完成证据

需要固定前后端版本、数据库迁移版本、测试命令、API 结果、浏览器证据及独立评审。每个测试数据必须明确租户与主体。当前只有旅程定义，不能将该清单作为已通过的结果。

## V3 新增检查：菜单和 Function 不等价

| Screen ID | 用户 | 预期结果 | 阻断反例 |
| --- | --- | --- | --- |
| S01-15 | 普通营销成员登录、选择可用企业 | 没有 Console 菜单也能使用营销入口并执行本人营销活动 | 直达后台任何业务页面拒绝，非本人活动 API 拒绝 |
| S01-16 | 有客户管理菜单但无 customer.read | 后台页面入口可见，但数据请求明确拒绝 | 菜单不能自动发出 Read/Update Function |

| S01-18 | 平台关闭 CRM 或营销模块 | 对应业务拒绝，角色本身 IAM Grants 保留 | 不修改已授权 Permission 作为模块开关副作用 |
