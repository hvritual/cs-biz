## 2. 可运行的业务范围

| 工作空间 | 已实现的行为 |
| --- | --- |
| 工作台 | 按当前可见客户计算统计和最近记录，权限控制快捷入口 |
| 客户管理 | 搜索、状态筛选、分页、详情、新建、编辑、归档、就近表单校验 |
| 团队成员 | 添加成员、分配角色、暂停和恢复访问、最后一名活动负责人保护 |
| 角色权限 | 创建、编辑、删除及逐操作设置范围；已使用角色不能直接删除 |
| 企业资料 | 权限控制读写、保存后刷新保留；其他页面更新不覆盖未提交资料 |

| 平台企业管理 | 独立平台身份、企业列表、处理开通申请、启用和暂停应用 |
| 个人偏好 | 浅色/深色/跟随系统、六种主色、两种密度、中文/英文；按用户和企业恢复 |

支撑状态包含账户选择、退出、深链接恢复、访问受限、页面不存在、加载、空结果、保存中、失败和重试。菜单使用固定本地视图注册表，权益和授权决定发布的路由；按钮与行操作同时反映可执行能力。

Mock 种子包含 **2 个企业、5 个账户、6 份成员关系、6 个角色、12 位客户**。青禾有 8 位客户且客户管理已开通，云岚有 4 位客户且初始未开通。持久化方式、账户权限、数据版本和重置方法见 [Mock 数据说明](../../frontend/doc/mock-data.md)。

浏览器测试监听页面异常、控制台 warning/error 和非主动取消的请求失败，并检查每个旅程结束时的可见文案及页面标题。未使用重试把偶发失败掩盖为通过。

### 浏览器业务断言

1. 客户创建前必填校验；双击保存不重复；搜索、编辑、刷新恢复、归档和分页有效。
2. 创建角色、添加成员、暂停/恢复访问；新成员最初没有客户，分配第一位客户后仅看到其范围内记录。
3. 可查看全部客户不扩大修改范围；另一标签页暂停成员后，旧表单、表格和动态路由及时清理，未提交数据不落入记录。
4. 企业切换清理当前表单；云岚申请开通后由平台批准；两企业数据互相隔离，关闭应用后旧页面失效。
5. 语言、主题、主色、密度保存后刷新恢复，企业偏好相互独立，系统模式随浏览器配色偏好变化。
6. 手机整体页面无横向溢出；表格内部可滚动，抽屉不超出视口；菜单可打开、导航后关闭。
7. 企业资料草稿不被其他标签页的客户更新覆盖，保存后刷新保留。
8. 退出后保持退出状态；安全深链接恢复；普通企业账户不能进入平台页面，未知页面有明确提示。
9. 启动数据损坏时有业务恢复页且不删除既有记录；外部修复后重试成功。
10. 初始化写入失败时不显示保存成功；恢复可写后重试成功。
11. 正常使用中资料变得不可读，切换账户仍显示业务错误及重试；保留资料，外部修复后可继续选择账户。

11 条流程均通过，没有页面未处理异常、浏览器控制台 warning/error，或非主动取消的资源请求失败。Shell 日志中的 `NO_COLOR` / `FORCE_COLOR` 提示来自本地进程环境，未被混入浏览器控制台结论。

## 5. 独立复核与实际修复

由实现之外的复核工作检查服务、上下文生命周期、页面渲染和交互，结论再通过运行验证。以下列出影响正确性的实际修复，不把排版偏好当作缺陷。

| 发现 | 修复与证明方式 |
| --- | --- |
| 同一 JS 环境中多个服务实例可能使用旧快照覆盖新授权或幂等回执 | 异步等待之后同步重读数据并重新授权，覆盖实例间竞争回归 |
| 重放成功创建命令依赖旧负责人/旧角色仍然有效 | 保留当前请求者重新授权，重放返回已存在结果，不重新执行旧业务副作用 |
| 初次持久化失败或浏览器存储不可用可能伪装为成功 | 明确返回存储失败；浏览器环境不静默改用内存，失败页可恢复 |
| 当前企业成员被暂停后自动切去另一企业 | 保留当前企业访问状态，清理旧内容；用户主动选择其他可访问企业 |
| 新加入成员无法成为首位客户的负责人 | 按 create/update 动作范围单独查询活动成员候选；服务及浏览器覆盖首次分配 |
| 企业资料草稿被无关客户更新覆盖 | 只在企业上下文改变时重新初始化草稿，保存后再同步资料 |
| 折叠图标依赖外部图标请求，初始国际化存在无效动态键 | 使用打包图标与可读名称，表格空行槽位先检查数据；浏览器不出现相应请求或警告 |
| 换肤后 Vben 导航与 Element Plus 主按钮颜色分裂 | 重复初始化曾创建两份同 ID 主题样式，改为同步注册唯一样式；单元回归及按钮、分页和品牌颜色一致性浏览器断言通过 |
| 运行期间账户数据损坏，账户选择页无法恢复 | 捕获账户读取失败，显示业务错误与重试；真实浏览器验证外部修复后恢复选择和工作空间 |
| 企业切换中外观操作可能写入上一企业 | 加载期禁用主题和语言操作并加方法保护；独立浏览器检查新企业完成后只写入其对应偏好 |
| 手机导航后菜单保持展开 | 应用布局在手机路由切换后收起菜单；实际验证打开状态、导航结果和关闭状态 |

测试编写中还修正了 Element Plus 控件的实际可访问名称和覆盖输入的选择器定位；使用可见控件或键盘操作，没有使用 `force` 点击绕开可用性问题。手机工作台的一级标题为“你好，陈予安”，导航验收检查真实路由和标题内容。
