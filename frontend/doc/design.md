# S01 前端界面设计与比对记录

> 本文保留 S01 初版的历史设计与验收记录。当前 Desktop 尺寸、主题和材质以 [CoffeeLink Desktop UI Contract](../../doc/design/desktop-ui.md) 为准；历史移动端与旧尺寸描述不是本次变更的实施要求。

本阶段实现以客户列表和新建客户抽屉两张内部概念图为视觉参考，使用 Vue 3、Vben 应用壳与 Element Plus 业务控件。参考图用来确定信息层级、布局和视觉语气；当前实现、已执行验收与最终截图比对分别记录，不把概念图描述成用户已审批或像素一致的交付。

本说明只覆盖前端界面。数据与操作事实见 [本地数据说明](mock-data.md)，实施范围见 [S01 任务](../../doc/tasks/S01-frontend-mock.md)。

| C01 客户列表 | `exec-7389938e-468d-493d-a00b-385acfa2ba15.png` | 青禾咖啡、陈予安、客户管理选中；标题、四项统计、筛选、八行客户、分页 |
| C02 新建客户 | `exec-c592bcc6-f19d-434f-b27c-8ac770db0ac8.png` | 保留同一个应用壳和客户列表，在右侧打开客户表单 |

原图为实现期间的设计参考，不作为应用运行时资源。应用壳、表格、图标、文字、状态与表单均由原生组件和 CSS 构成；不把整张截图铺成页面。

### 归一化目标

| 项目 | 规格 | 意图 |
| --- | --- | --- |
| 侧栏 | 展开宽 220px；折叠宽 64px | 保留稳定的企业工作空间导航，给主表格足够宽度 |
| 顶栏 | 高 64px | 左侧企业选择，右侧主题、语言和账户操作 |
| 主色 | `#0f766e` | 用于主要操作、选中状态和焦点；避免整页大面积高饱和背景 |
| 页面底色 | `#f6f8fa` | 与白色内容面形成轻度层次 |
| 内容面 | 白色、1px 细边框、8px 圆角 | 表格和表单保持清楚的边界 |
| 字体 | 系统无衬线；正文 14px；主标题目标 24px | 兼顾中文密度、英文长度与长时间阅读 |
| 内容边距 | 桌面水平约 32px，页面顶部约 30px | 标题、统计与表格共享左对齐线 |
| 客户抽屉 | 450px；最大宽度不超出视口 | 同一上下文内完成创建、编辑和详情查看 |
| 遮罩 | 目标约 15% 深色透明度 | 保留列表上下文，强调当前表单 |
| 操作布局 | 标题右侧一个主要操作；抽屉底部右对齐取消和保存 | 明确下一步，避免重复主要按钮 |
| 信息表现 | 轻量统计带、表格、二级文字、文字状态标签 | 直接呈现客户与工作信息 |
| 品牌 | `CS Biz` 文字，由代码排版 | 无需独立图片 Logo 或装饰插画 |

生成图的侧栏、标题、抽屉和遮罩存在尺寸偏差：主图侧栏约 246px，标题约 30–32px；第二张图的抽屉约 436px，遮罩更深。这些是参考图观察值，不能替代归一化目标。业务名称、状态、数量与表单字段以当前数据和语言包为准，避免复制生成图中的文字误差。

## 2. 应用壳与八个业务页面

[应用布局](../apps/console/src/layouts/basic.vue) 复用 Vben `BasicLayout`，业务页面不再绘制第二套侧栏或顶栏。顶栏内容见 [WorkspaceShellTools](../apps/console/src/components/WorkspaceShellTools.vue)，菜单和本地视图映射见 [routing.ts](../apps/console/src/platform/routing.ts)。

企业菜单随有效权限和应用权益变化。平台账户进入独立的企业管理工作空间，顶栏显示平台上下文，不借用任一家企业的菜单。页面不保留页签缓存，切换企业、账户或访问权限后关闭旧表单并清理旧内容。主题、语言和账户按钮具有业务名称与键盘焦点；手机侧栏展开、导航后收起及可访问名称/状态已在浏览器核对。

| 页面 | 布局与主要信息 | 主要动作与结果 |
| --- | --- | --- |
| [工作台](../apps/console/src/views/overview/index.vue)，`/overview` | 问候和企业说明、四项统计；桌面左侧最近客户，右侧快捷入口和工作空间说明 | 根据权限进入客户、成员、应用或资料；没有客户访问能力时提供合适的应用入口 |

| [企业资料](../apps/console/src/views/settings/index.vue)，`/settings` | 最大宽 780px 的资料面，企业名称和建立日期；联系人、电话、邮箱表单 | 有编辑权限时保存；只读状态保留清楚的资料内容和业务说明 |

### 客户列表的信息层级

标题为“客户管理”，说明为“统一管理客户关系与服务信息”，右侧主要动作为“新建客户”。统计带使用“客户总数、合作中、洽谈中、暂停合作”；青禾种子数据为 8 / 5 / 2 / 1，所有数值随当前有权查看的数据更新。

表格按客户名称、联系人、联系电话、负责人、合作状态、最近更新、操作排列。客户名称下方使用较小的类型说明；状态同时使用文字和轻量底色，不靠颜色单独表达。表格默认每页 10 条，可以切换 5 / 10 / 20 条。筛选结果为空时给出“没有找到符合条件的客户”和清除筛选入口；尚无客户时使用另一组首条记录说明。

### 客户创建与编辑

抽屉字段依次为客户名称、客户类型、联系人、联系电话、负责人、合作状态、备注。标签置于控件上方，字段错误就近展示；备注使用多行输入。底部保留“取消”和“保存客户”，保存中显示进行状态并限制重复操作。

表单只在实际操作完成后关闭并显示成功。切换账户或企业时不能把旧表单提交到新企业；结果尚未确认的创建记录按原账户、企业和操作恢复。归档确认说明客户将从日常列表移出且资料保留，不使用含糊的“确定执行”文案。权限不足时隐藏不可用行操作，服务仍独立校验访问权限。

角色抽屉沿用相同阅读方向，但为权限表格扩大宽度。原 RoleGrantEditor 的职责现由 [PermissionSetEditor](../apps/console/src/components/PermissionSetEditor.vue) 承接；“查看全部客户”不会在界面上暗示其他操作也拥有全部范围。

## 3. 中英文、主题和密度

### 文案与语言

语言入口在顶栏和个人偏好页。当前支持 `zh-CN` 和 `en-US`，应用文案、动态菜单、表单校验、错误提示与 Element Plus 组件语言通过 [locales](../apps/console/src/locales/index.ts) 一起切换；日期和数量通过 [format.ts](../apps/console/src/utils/format.ts) 按当前语言格式化。企业名称、姓名、客户名称等业务数据保持原值，不因英文界面而生成另一份数据。

英文通常占据更多横向空间。页面标题和说明允许正常换行，工具栏可以折行，按钮保持完整操作名称；窄屏通过纵向重排解决空间不足。数字和状态不以语言包中的静态句子代替当前数据。语言名称“简体中文 / English”保留自称，主色选择按钮有可读名称和选中状态。

### 浅色、深色与主色

主题模式为浅色、深色和跟随系统。主色为受控六色：`#0f766e`、`#4f46e5`、`#2563eb`、`#7c3aed`、`#c2410c`、`#475569`。初始青禾使用青绿色，云岚使用靛蓝色；个人在对应企业的选择覆盖默认颜色，切回原企业恢复该企业下的个人偏好。实现入口见 [appearance store](../apps/console/src/store/appearance.ts)。

| 语义 | 浅色 | 深色 |
| --- | --- | --- |
| 页面 | `#f6f8fa` | `#11171f` |
| 内容面 | `#ffffff` | `#1a222d` |
| 次级底色 | `#f5f7f9` | `#202b38` |
| 正文 | `#182230` | `#e8edf3` |
| 次级文字 | `#667085` | `#a4b1c1` |
| 边框 | `#e4e7ec` | `#334051` |

状态另有成功、提醒、危险的前景与背景 token，深色模式不只改变页面底色。表格、抽屉、表单错误、选中态和主要按钮已检查；对比度或全量无障碍认证没有以截图结果代替专门验收。最终修复主题重复样式后，紫色下品牌、Element Plus 创建/保存按钮和分页的背景一致，合作状态仍使用独立语义色。

### 密度

舒适密度下，表格单元格垂直 padding 为 10px；紧凑密度为 8px。紧凑模式将页面顶部留白调整为 22px，列表行垂直 padding 调整为 12px。密度改变信息占用空间，正文保持 14px，字段名称与操作名称保持可读。

## 4. 响应式与可访问操作

页面最小宽度为 320px。桌面内容最大宽度为 1680px，随侧栏占位调整。窄屏保留客户表格的列语义，由表格区域内部滚动；不能通过整体页面横向溢出来容纳桌面表格。真实滚动行为以浏览器验收为准。

| 范围 | 当前实现策略 |
| --- | --- |
| 1100px 以下 | 页面留白缩为 24px；工作台双栏变为单列 |
| 767px 以下 | 顶栏隐藏辅助工作空间标签和账户姓名，保留带名称的账户按钮；企业选择控件缩窄，侧栏采用 Vben 移动布局 |
| 760px 以下 | 应用详情的三项用途改为单列，状态和动作纵向排列 |
| 640px 以下 | 页面左右留白 16px；标题区域可换行；统计为两列；工具栏输入和选择控件占满可用宽度；表单双栏变为单列 |
| 480px 以下 | 角色权限表格缩小范围列；账户选择页收紧内边距；核心字段和操作仍保留可读名称 |
| 客户抽屉 | 桌面 450px，最大宽度 `100vw`；小屏表单区域 padding 20px，底部操作仍在抽屉内 |

键盘焦点有可见轮廓。图标按钮提供业务名称，状态标签保留文字；加载使用状态播报，错误使用警示语义。系统要求减少动态效果时，页面动画与滚动过渡缩短。浏览器实际执行角色选择器键盘操作、窄屏菜单和抽屉、英文校验与按钮；验证范围不等同于完整键盘/读屏器认证。

## 5. 界面文案原则

界面直接说明用户正在处理的业务及可采取的下一步。不得在标题、按钮、提示、空状态、弹层、菜单或浏览器标题中出现“未接入、未对接、开发中、待开发、占位、演示数据、模拟数据、Mock、API、backend、frontend”等实现或环境标签；仓库文档和测试可以准确记录这些术语。

| 场景 | 当前文案方向 | 与行为的关系 |
| --- | --- | --- |
| 添加成员 | “添加成员”“成员已添加” | 建立本地账户或企业成员关系，不声称发送邮件 |
| 客户保存 | “保存客户”“客户资料已更新” | 只在服务实际成功后反馈 |
| 应用申请 | “申请开通”“申请处理中”“开通申请已提交” | 申请记录存在后显示；不声称已经收费或自动开通 |
| 访问暂停 | “访问已暂停”及联系企业负责人的说明 | 解释用户状态，避免暴露权限码或调用细节 |
| 筛选无结果 | “没有找到符合条件的客户”“清除筛选” | 保留当前任务，提供明确恢复路径 |
| 首次没有记录 | “还没有客户”与创建首份档案的说明 | 与筛选无结果区分 |
| 启动失败 | “暂时无法打开工作空间”“重新打开” | 可以重试，保持已有记录，不渲染异常栈或存储错误详情 |

不使用“邮件已发送”“支付成功”等没有实际操作支持的反馈。未知错误映射到可理解的业务提示，不能把异常对象、错误码或依赖名称直接插入页面。用户自己输入的业务资料保留其原文，文案扫描的目的在于约束应用提供的提示。
