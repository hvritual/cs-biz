# 前端部署与静态预览

S01 可以构建一个静态 Vue SPA，产物为 `frontend/apps/console/dist`。本文件定义该产物的预览方式与后续托管条件；本阶段没有执行线上部署，也没有交付运行中的容器或已发布环境。

## 构建产物

以下命令的工作目录为仓库的 `frontend`。使用 Node.js 22.18.0 及以上的 22.x 或 24.x，并通过 Corepack 使用 `pnpm@10.33.4`：

```sh
corepack enable
corepack install
pnpm install --frozen-lockfile
pnpm build
pnpm preview --host 127.0.0.1 --port 5778 --strictPort
```

预览地址为 <http://127.0.0.1:5778>。构建输出由 `apps/console/dist` 提供，本地预览用于人工检查；浏览器自动检查由 [前端 CI](../ci/README.md) 管理自己的预览进程。

## 静态托管条件

| 项目 | 配置要求 |
| --- | --- |
| 网站根目录 | 指向 `apps/console/dist` 的内容 |
| 默认路径 | 当前构建以 `/` 为站点根路径 |
| SPA history 回退 | `/customers`、`/members`、`/settings` 等业务深链接返回 `index.html`，交由 Vue Router 处理 |
| 静态文件缺失 | 不存在的脚本、样式和图片返回真实 404，避免把 HTML 当作资源返回 |
| 入口缓存 | `index.html` 使用可重新验证的缓存策略，避免长期停留在旧资源入口 |
| 内容哈希资源 | 带内容哈希的资源可以采用长缓存，更新通过新文件名生效 |
| 发布检查 | 从新页面直接打开业务深链接并刷新，确认路由、资源路径、语言与主题正常 |

部署在子路径时需同时调整构建资源基路径和路由基路径，并重新执行深链接与资源加载检查。配置中仅使用浏览器可公开的信息；真实凭据和服务端授权规则属于后端运行环境。

## S01 数据与运行边界

当前业务数据保存在浏览器来源对应的 LocalStorage，身份和企业选择按标签页保存。换用其他站点来源、浏览器配置或清除站点数据，会影响该本地数据集；静态资源发布本身不会把这些记录同步到服务端。[Mock 数据说明](../doc/mock-data.md) 记录种子、恢复方式和限制。

账户选择和权限展示用于本阶段前端体验。实际认证、API、数据库、服务端租户隔离和发布环境需要后续任务落实。Vite 本地预览与前端单元测试不构成这些能力的上线证据。

跨端启动、集成环境与跨端验收由 [全局 CI](../../doc/ci/README.md) 编排；本目录负责前端静态资源的运行条件。实际发布时再补充对应环境的发布、健康检查与回滚资产，并记录部署结果。
